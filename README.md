\# OnomasticsDataSystem



Webová aplikácia na analýzu mien a priezvisk.



\## 📌 Popis projektu

Tento projekt umožňuje:

\- vyhľadávať mená a priezviská

\- filtrovať podľa mesta a roku

\- zobrazovať štatistiky (Top mená, výskyty)

\- vizualizovať dáta pomocou grafov



\## 🏗️ Architektúra

Projekt je rozdelený na viacero častí:



\- `OnomasticsDataSystem.Web` → frontend (Blazor)

\- `OnomasticsDataSystem.Core` → business logika

\- `OnomasticsDataSystem.Infrastructure` → databáza

\- `OnomasticsDataSystem.DataImport` → spracovanie dát



\## ⚙️ Technológie

\- .NET / C#

\- Blazor

\- Entity Framework Core

\- SQL databáza
